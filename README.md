# Flutter Laboratory Activities 1–5

## Project Description

This project contains five Flutter laboratory activities for practicing Flutter architecture, widgets, layouts, state management, and basic UI design.

## Activities

1. **Activity 1 – Profile Card:** Displays student information using Flutter widgets.
2. **Activity 2 – Water Tracker:** Demonstrates state management using `setState()`.
3. **Activity 3 – Weather Layout:** Practices responsive layouts and the `Expanded` widget.
4. **Activity 4 – Café Menu:** Displays menu items using a grid layout and reusable widgets.
5. **Activity 5 – Settings and Theme Components:** Demonstrates dark mode, switches, chips, theme customization, and a save button.

## Requirements

- Flutter SDK
- Dart SDK
- Visual Studio Code or another Flutter-compatible IDE

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal in the project directory.
3. Run `flutter pub get`.
4. Run `flutter run`.

## Validation

Run the following commands to check the project:
